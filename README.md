# 功能自述

面向科研 / 统计场景的桌面绘图工具，用 PySide6 实现，界面为
木系风格（左侧菜单 + 右侧内容区）。目标：把常用的统计数据可视化做成
「拖入数据 → 调参 → 出图」的可视化操作，无需手写 matplotlib / seaborn 代码。

---

## 一、它能做什么

1. **数据透视**：拖入 Excel / CSV 表格后，自动识别列类型、统计空值、生成描述性
   统计表（describe），并可一键绘制箱线图、导出 Excel。
2. **绘图（24 种图形）**：覆盖关系图、分布图、分类图、回归图、热力图、分面图
   六大类，全部由左侧菜单分组进入。
3. **拖拽式配置**：每个图形页面提供拖拽槽（把列名拖到 X / Y / 分组等位置）和参数
   控件（颜色、标记、分箱数等），改完即时重绘。
4. **代码生成**：出图同时给出等价的 seaborn 代码，图与代码保持一致，方便复用到
   脚本里。
5. **自持数据**：每个页面独立读取自己的文件，互不干扰；页面常驻不销毁，切换菜单
   后已配好的参数与图都会保留。

---

## 二、功能模块（左侧菜单）

| 菜单项 | 包含图形 |
|---|---|
| 数据透视 | 空值统计 / 描述统计 / 箱线图 / Excel 导出 |
| 绘图 | 散点图、折线图、箱线图、直方图、柱状图、计数图、点估计图、小提琴图、散点条图、蜂群图、增强箱线图 |
| 分布 | 核密度图、累积分布图、边缘地毯图 |
| 回归 | 回归图、残差图 |
| 热力图 | 热力图、聚类热图 |
| 分面 | 联合分布图、成对矩阵图、关系分面图、分布分面图、分类分面图、回归分面图 |

> 菜单分组可点击展开 / 收起；点击子项切换到对应绘图页。

---

## 三、典型使用流程

1. 启动程序（见下方「运行方式」），进入欢迎页。
2. 左侧选「数据透视」拖入数据表，查看空值与统计；或选任一图形分组下的子项。
3. 在图形页把列拖进 X / Y / 分组等槽位，调整参数，右侧即时出图。
4. 需要代码时，从代码区复制生成的 seaborn 脚本。
